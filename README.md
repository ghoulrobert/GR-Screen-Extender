# GR 扩展屏幕 - 项目说明

## 项目概述

GR 扩展屏幕是一个跨平台的屏幕扩展解决方案，让您的手机、平板或另一台电脑秒变扩展显示屏。

### 核心特性

- 📱 **多设备支持** - 安卓手机/平板/Win电脑均可作为扩展屏
- 📡 **WiFi 连接** - 局域网无线连接，低延迟传输
- 🔌 **USB 连接** - 后续支持 USB 有线连接（规划中）
- 🎮 **触摸回传** - 支持触摸操作回传主机
- 🖱️ **鼠标键盘** - 支持鼠标操作和键盘输入
- 🎬 **硬件编解码** - H.264 硬件加速，降低 CPU 占用
- 🔍 **设备发现** - 自动发现局域网内的主机

## 快速开始

### 主机端 (Windows)

#### 环境要求
- Windows 10/11
- .NET 6.0 或更高版本
- 支持 DirectX 11 的显卡

#### 运行
```bash
cd server/ScreenServer
dotnet run
```

### 客户端 (Android)

#### 环境要求
- Android 7.0 (API 24) 或更高版本
- 支持 H.264 硬解码的设备

#### 构建
```bash
cd client
./gradlew assembleDebug
```

### 使用步骤

1. **启动主机端**
   - 在 Windows 电脑上运行 `ScreenServer.exe`
   - 确认防火墙允许程序网络访问

2. **连接客户端**
   - 在 Android 设备上安装并打开 GR 扩展屏幕
   - 输入主机 IP 地址
   - 点击"连接"按钮

3. **开始使用**
   - 手机/平板屏幕将显示电脑桌面
   - 触摸屏幕可控制电脑光标
   - 支持键盘输入回传

## 通信协议

| 通道 | 端口 | 协议 | 用途 |
|------|------|------|------|
| 控制通道 | 33891 | TCP | 设备配对、命令传输 |
| 视频通道 | 33892 | UDP | H.264 视频流 |
| 输入通道 | 33893 | TCP | 触摸/键盘事件回传 |
| 发现通道 | 33894 | UDP | 设备自动发现 |
